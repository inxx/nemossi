# 네모씨 요구사항

## 목표

네모씨는 사용자가 이미 대화하고 있는 **같은 dot의 통화를 작은 단말에서 사용하는 것**이 목표다. 별도 LLM이나 새 Realtime API 세션을 dot 연결과 동등하게 취급하지 않는다. Muse SDK 통합은 최종 요구에서 제외되었다.

하드웨어는 **Waveshare ESP32-S3-Touch-LCD-1.54**다. Mac mini는 연결 중계와 개발 호스트 역할을 맡는다. 보드에는 ESP32-S3R8, Flash 16MB, PSRAM 8MB, ST7789 240×240 SPI LCD, CST816 I2C 터치, ES7210 입력 ADC, ES8311 출력 코덱, NS4150B 앰프, QMI8658 IMU가 있다. 정확한 GPIO와 공식 소스는 [hardware.md](hardware.md)에 기록한다.

## 현재 개발 방향

스마트안경 없이 현재 네모씨 보드 기준 개발을 계속한다. Mac mini 공통 허브와
네모씨 디바이스 계층을 분리하고, 시뮬레이터에서 연결·입력·응답·재생·취소·복구
흐름을 검증한다. 장래 스마트안경은 별도 프로젝트에서 준비하며 폰 등 외부
릴레이를 거쳐 Mac mini와 연결할 수 있다. 안경의 Mac 직접 연결이나 USB 전용
최종 형태를 가정하지 않는다.

## 기능과 검증 범위

| 요구 | 첫 결과 범위 | 완료를 증명하는 방법 |
| --- | --- | --- |
| 같은 dot 통화의 마이크·스피커 단말 | 공식 연결 경로 조사, transport 경계 분리 | 공식 세션/오디오 지원과 동일 dot 확인 후 실물 통화 |
| Stack-chan 스타일 얼굴 | 이미지 복사 없이 primitive 렌더링, 240×240 | 브라우저 표시와 순수 C 얼굴 모델 테스트 |
| 얼굴 상태·애니메이션 | idle/blink/gaze/listening/thinking/speaking/happy/confused/error/sleep | 상태 전환 및 재생 중 입 움직임 확인 |
| 말하기·취소·설정 | 데모와 선택적 브라우저 마이크 입력, 볼륨·밝기 | mock WAV 요청·응답·재생, 취소와 오류 복구 |
| +KEY push-to-talk | 보드 이벤트와 상태 모델 골격 | 호스트 테스트; 실제 GPIO 입력은 보드에서 확인 |
| 터치 Talk/Cancel/Settings | 브라우저 UI, 공식 핀 기반 펌웨어 골격 | 실물 터치 입력 검증은 후속 |
| Wi-Fi 연결 | 자격 증명 없이 실행 가능한 데모와 보드 설정 경계 | 사용자 설정 후 실제 연결·끊김 시험 |
| 마이크 입력·스피커 출력 | 16kHz mono PCM16 WAV 프로토콜, 보드 오디오 경계 | ES7210/ES8311 초기화·녹음·재생은 실물 후속 |
| 안전한 실패 처리 | 잘못된 WAV·요청·오류·취소 처리, 무한 재부팅 방지 | HTTP 통합 테스트와 C 상태 테스트 |
| 빌드와 실행 방법 | 설치 없는 Python 서버, IDF 골격 및 빌드 명령 | 현재 도구로 테스트; IDF cross build는 별도 |
| 장치 연결·복구 | Mac hub와 단일 네모씨 lifecycle, 브라우저·CLI 시뮬레이터 | 연결·끊김·재연결·오류 복구 및 늦은 응답 거절 |
| 미래 스마트안경 경계 | 외부 릴레이를 허용하는 예약·미지원 정보만 제공 | 안경 실행 코드는 별도 프로젝트; 현재 실제 연결 주장 없음 |

## 얼굴 디자인

두 눈과 하나의 입을 중심으로 Stack-chan의 단순한 얼굴 경험을 재현한다. 기본 화면은 얼굴이 대부분을 차지하고 자막은 필요한 순간에 짧게 표시한다. 랜덤 눈 깜빡임, 작은 시선 이동, 듣는 표정, 생각하는 표정, 재생 음량에 따른 입 움직임을 별도 렌더 루프로 처리한다. IMU 기울기 반응은 이후 실물 검증 대상으로 남긴다.

## 연결 원칙

현재 구현한 `mock`은 로컬 장치와 상태 흐름을 검증하기 위한 데모다. 실제 dot 응답·음성인식·TTS가 아니며 합성 확인음을 사용한다. 실제 dot 연결 여부는 항상 별도로 표시한다. 미확인 연결은 연결 성공으로 표시하지 않는다.

## 현재 범위의 제약

- 비공개 앱 API 역공학, 로그인 토큰 추출, 인증 우회 금지.
- SDK 신규 설치, 실물 플래시·오디오 테스트, 자격 증명 생성·설정, 유료 API 호출, 지속 서비스 등록은 필요 시 대상과 범위를 먼저 보고한다.
- Wi-Fi 비밀번호·장치 토큰은 코드·로그·Git에 넣지 않는다.
- 기존 저장소 `main`만 사용하고, 무관한 저장소와 변경 사항은 보존한다.
- 현재 범위는 통화 단말이다. 셀룰러 전화, 일정·홈 자동화·알림·대화 기억의 추가 서비스는 후속 검토 대상이다.
