# 네모씨 요구사항

## 목표

2026-10-05 사용자는 **PLUS push-to-talk → Muse 답 → Mac 로컬 TTS → 보드 스피커와 입 움직임**으로 방향 전환을 승인했다. 기존 Stack-chan 기본 얼굴과 여섯 표정은 유지한다. 기존 ChatGPT dot과는 별도 Muse 대화이며, 같은 dot 연결로 표시하지 않는다. [빌드·연결 절차](muse-connection.md).

하드웨어는 **Waveshare ESP32-S3-Touch-LCD-1.54**다. Mac mini는 연결 중계와 개발 호스트 역할을 맡는다. 보드에는 ESP32-S3R8, Flash 16MB, PSRAM 8MB, ST7789 240×240 SPI LCD, CST816 I2C 터치, ES7210 입력 ADC, ES8311 출력 코덱, NS4150B 앰프, QMI8658 IMU가 있다. 정확한 GPIO와 공식 소스는 [hardware.md](hardware.md)에 기록한다.

## 현재 개발 방향

스마트안경 없이 현재 네모씨 보드 기준 개발을 계속한다. Mac mini 공통 허브와
네모씨 디바이스 계층을 분리한다. 기존 시뮬레이터는 mock 흐름을 검증하고,
새 Muse 포트는 별도 SDK 빌드와 호스트 검사로 입력·응답·재생·취소를 검증한다.
실물 연결은 사용자 설정과 구체적인 이미지 업로드 승인 후 확인한다. 장래 스마트안경은 별도 프로젝트에서 준비하며 폰 등 외부
릴레이를 거쳐 Mac mini와 연결할 수 있다. 안경의 Mac 직접 연결이나 USB 전용
최종 형태를 가정하지 않는다.

## 얼굴 디자인

공식 기본 SimpleFace의 검정 배경, 흰 원형 눈 두 개와 직사각형 입을 재현한다. 원본 320×240 전체를 0.75배로 줄이고 위아래 30픽셀 여백을 두어 원형 눈과 간격을 늘이거나 눌리지 않게 한다. 눈 깜빡임은 고정된 원을 eyelid mask로 가리고, 말하기는 원본 입 너비·높이 식에 기존 재생 음량을 적용한다. Listening 전용 얼굴을 새로 만들지 않으며 대화 상태 표시는 얼굴 밖에 둔다. 브라우저와 C는 같은 파라미터를 사용한다. [원본·수정 대조](face-reference.md). IMU 기울기 반응은 이후 실물 검증 대상으로 남긴다.

선택 가능한 여섯 표정은 공식 원형 눈·직사각형 입 위에 얹은 네모씨 파생
디자인이며 대화 상태와 분리한다. 기본 얼굴은 위의 공식 비율 그대로 유지한다.
[표정 수치와 동작](expressions.md).

## 연결 원칙

기존 `mock`은 합성 확인음을 사용하는 로컬 상태 데모다. 새 Muse 포트와 Mac TTS 구현은 별도 경로다. 토큰 없는 빌드와 호스트 검사 통과는 실제 Muse·하드웨어 연결 성공을 뜻하지 않는다. 실제 연결을 확인하기 전 성공으로 표시하지 않는다.

## 현재 범위의 제약

- 비공개 앱 API 역공학, 로그인 토큰 추출, 인증 우회 금지.
- 분리된 IDF 6.0.1·공식 Muse SDK 준비와 기기 없는 빌드·검사는 승인 범위다. 계정·토큰·LAN 실행·Wi-Fi 저장 및 실제 이미지 업로드는 필요한 구체적 범위를 사용자에게 확인한다. 유료 API와 지속 서비스는 설정하지 않는다.
- Wi-Fi 비밀번호·장치 토큰은 코드·로그·Git에 넣지 않는다.
- 기존 저장소 `main`만 사용하고, 무관한 저장소와 변경 사항은 보존한다.
- 현재 범위는 PTT 음성 단말이다. 셀룰러 전화, 일정·홈 자동화·알림·대화 기억의 추가 서비스는 후속 검토 대상이다.
